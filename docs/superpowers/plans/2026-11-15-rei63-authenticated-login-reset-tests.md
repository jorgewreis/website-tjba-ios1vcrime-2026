# REI-63 Authenticated Login and Reset Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish isolated automated coverage for login, password reset, and logout without real users, data, mail, or production.

**Architecture:** Extend the REI-64 disposable MySQL/Mailpit sandbox with synthetic active and inactive users. Add direct service tests for deterministic policy and rate-limit behavior, then a local HTTP runner with a cookie jar to exercise CSRF, sessions, redirects, reset mail capture, and logout. Keep HTTPS-cookie browser evidence explicitly separate because the current sandbox is HTTP-only.

**Tech Stack:** PHP 8.2 CLI/server, PDO MySQL/InnoDB, PHPMailer, PowerShell, Docker Compose, Mailpit.

**Spec:** Linear REI-63; `tests/auth/` sandbox established by REI-64.

## Global Constraints

- Use only MySQL/Mailpit data generated in `tests/auth/`; never load the root `.env` or data from production.
- Test users, addresses, URLs, and messages use the `auth-test.invalid` domain.
- Do not publish, deploy, use real credentials, or send external email.
- Preserve unrelated worktree changes and never stage broadly.
- Treat HTTP-only validation as insufficient evidence for HTTPS `Secure` cookies, browser iframe behavior, or production parity.

## Review Focus

- Missing or invalid CSRF must fail before any login, reset, or logout side effect.
- Unknown and known reset requests must expose the same application response while Mailpit only receives mail for the synthetic known account.
- A successful login must clear both CPF and IP rate-limit scopes; invalid attempts must not clear either.
- An expired or already used token must not alter the user password or consume another valid token.
- Cookie-jar HTTP tests must follow the actual session and redirect contracts, while reporting HTTPS `Secure` cookie verification as pending.
