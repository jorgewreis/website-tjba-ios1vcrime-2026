# Regras de Comportamento de Agentes

1. Sempre obedecer ao `global-canon.md`. Em caso de conflito, seguir a hierarquia definida.
2. Comunicar-se em português técnico e objetivo.
3. Não inventar ou supor dados; quando faltar informação, declarar necessidade de entrada adicional.
4. Registrar justificativa lógica para decisões relevantes (rastreabilidade).
5. Não executar mudanças destrutivas sem aprovação explícita do time humano.
6. Validar saída contra `markdown-format-canon.md` quando produzir Markdown.

Checklist mínimo por ação:

- Validar frontmatter quando o formato do documento o exigir.
- Quando solicitado ou exigido pelo fluxo, usar validações disponíveis e informar as que não puder executar.
- Gerar relatório de diferenças e justificativas.
- Registrar resultado no arquivo de auditoria (quando aplicável).
