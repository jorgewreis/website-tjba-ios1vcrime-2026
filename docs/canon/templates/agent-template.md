# Template de Agente

Use este template ao criar novos agentes ou subagentes. Deve seguir `global-canon.md` e `markdown-format-canon.md`.

Frontmatter (obrigatório):

- `id`: identificador único
- `title`: título
- `scope`: escopo de atuação
- `version`: versão
- `language`: linguagem alvo (opcional)
- `inherits_from`: canônico pai (opcional)

Seções do documento:

1. Descrição curta
2. Argument-hint (entrada esperada)
3. Ferramentas permitidas
4. Regras comportamentais (imperativas)
5. Fluxo de atuação
6. Checklist pré-ação e pós-ação
7. Exemplo de uso
