Sistema - Erro HTTP

401 — Acesso não autorizado

401

A página que você está tentando acessar requer autenticação.

O erro 401 significa que o sistema exige identificação válida para permitir o acesso ao conteúdo solicitado. Em regra, ocorre quando a sessão expirou, o usuário não realizou login ou as credenciais informadas não foram reconhecidas. É um mecanismo de proteção, semelhante ao controle de acesso a áreas restritas: é necessário possuir autorização formal para ingressar. Para resolver, realize novo login e verifique se seu perfil está adequado às permissões exigidas. Persistindo o problema, contate o suporte responsável pela gestão de usuários do sistema.
