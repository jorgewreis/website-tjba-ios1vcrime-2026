Referência — Componentes / Botões

Contrato de botões

Base btn + variante; ordem: btn → variante → utilitários (height-sm, etc.). Todo <button> com type explícito. Regra completa: .cursor/rules/ui-buttons-contract.mdc.

1. Variantes de cor (tamanhos base, médio e grande)

Ordem: btn → variante → btn-large / btn-small quando necessário.

2. Rodapé de formulário / barra de ações

Padrão comum: secundário (voltar/cancelar) + primário (salvar). Ajuste variantes ao fluxo (ex.: btn-danger-outline para cancelar operação).

<button type="button" class="btn btn-secondary height-md">Voltar</button> <button type="submit" class="btn btn-primary height-md">Salvar</button>

3. Linha de tabela — editar (ícone)

Sempre btn btn-editar. Sem texto visível: aria-label e title iguais.

(demonstração isolada; na listagem real fica na célula de ações)
<button type="button" class="btn btn-editar" title="Editar" aria-label="Editar"><i class="fi fi-rr-pen-square"></i></button>

4. Navegação por botão (data-nav-href)

Substitui <a href> para ações de UI. Requer navigate-buttons.js. Nova aba: data-nav-target="_blank".

<button type="button" class="btn btn-primary height-md" data-nav-href="/frame.php?page=...">Texto</button>

5. Exceções ao par btn + variante (lista v1)

Estes padrões não usam variante de cor do btn; ver tabela na regra ui-buttons-contract.mdc.

  • Toast: toast-close — exemplo abaixo.
  • Paginação: pagination-symbol, pagination-number; reticências em span.pagination-ellipsis.
  • Badge PDF: badge file + data-nav-href (botão ou estilo equivalente).
  • Link em texto: link-inline, btn-link-badge.
